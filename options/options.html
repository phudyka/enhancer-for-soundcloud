Mode du bouton « Aléatoire »
Le mode complet charge la file sans API, puis lance le mélange SoundCloud. Shuffle+ crée une playlist privée.
Position de l’onglet du panneau latéral
Place le bouton d’ouverture du même côté que le panneau choisi dans le navigateur.
